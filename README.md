# RyM Dedicatorias | SKU: D-001

Dedicatoria web interactiva personalizada para clientes de **RyM Joyería**.
Diseñada para ser escaneada mediante código QR en el estuche o tarjeta del regalo.

## ✨ Características de la Web
1. **Unboxing Virtual (Sobre 3D con sello de lacre dorado):** Experiencia táctil donde María Elena abre el sobre y se inicia la reproducción musical de forma armónica.
2. **Reproductor Musical Flotante:** Con animación de vinilo giratorio y controles de pausa/reproducción.
3. **Carta manuscrita con estética de Joyería:** Tipografías clásicas (*Cormorant Garamond* y *Montserrat*) enmarcadas con detalles dorados.
4. **10 Momentos Inolvidables:** Selección curada en formato Polaroid con títulos románticos.
5. **Colección Completa (30 Fotos):** Cuadrícula complementaria de 20 fotografías con Lightbox interactivo (soporta gestos táctiles Swipe en móviles y flechas de teclado en PC).
6. **Lienzo de Partículas:** Caída suave de pétalos de rosa y destellos dorados.
7. **Detalle Interactivo:** Botón de envío de latidos con corazones flotantes y contador persistente en localStorage.
